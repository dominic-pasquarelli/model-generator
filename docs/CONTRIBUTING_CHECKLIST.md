# Contribution Checklist

Use this as a lightweight PR or branch closeout checklist.

- Does the change preserve the Board Mount Designer first-slice focus?
- Did any architecture, workflow, or tool-contract rule change?
- Is the relevant ADR Accepted, Proposed, superseded, or still open?
- Did built behavior, tests, evidence, and documentation move together?
- Is `docs/NEXT.md` still short, active, and resumable?
- Did completed work move to `docs/HISTORY.md`?
- Did captured or deferred ideas get a destination or recall trigger?
- Did `docs/TECH_DEBT.md` get a stable ID for accepted limitations?
- Was `docs/MAP.md` regenerated?
- Did `python3 tools/doc-audit/doc_audit.py --check` pass?
