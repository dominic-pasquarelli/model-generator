# model-generator
This project is designed to be a tool that I can build on to knock out common model inconveniences that I have or to reduce common things and speed up time in the general modeling process.

## Possible Features
### Board Mount Designer
A common gripe when making electronics enclosures or just working with PCB's and dev boards.  Having a tool where an image of a board can be uploaded, mounting holes positioned, keep out zones designed.  Then from there important measurements can be prompted to get hole sizes and spacing.  Then from there a bracket structure could be generated that can then be visualized in 3d and then imported into 3d modeling software.  Eventually we can add things like mounting tabs, stands, and other things to make saving/working with it easier.

### Board Assembly
This would be a later add on to the board mount designer but the ability to combine different board mounts to make a internal structure that connects all of them together that could then make an electronics pod that an actual enclosure could be designed around.  I am thinking things like header clearance, wire paths, power and port positioning and other things could be established for each board/board mount and a structure designed to stack everything and route wires efficiently and modular.
